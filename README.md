Crowned by Yanga Website

Project Overview

Crowned by Yanga is a salon website developed for the Web Development module. The website showcases salon services, hairstyle inspiration, booking enquiries, contact information, and interactive features.

Pages Included

* Home
* About
* Services
* Gallery
* Booking
* Contact

Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

Features

* Responsive website design
* Interactive booking enquiry form
* Interactive contact form
* Form validation using JavaScript
* Service search and filtering functionality
* Image gallery
* Embedded Google Map
* Social media buttons
* SEO optimisation

SEO Improvements

* Meta descriptions added to all pages

* sitemap.xml implemented
