Project Overview

Crowned By Yanga is a salon website designed to showcase hairstyling services and allow customers to enquire about bookings online. The website provides information about the salon, available services, a gallery of hairstyles, a booking enquiry form, and a contact page.

⸻

Features Implemented

Navigation

* Multi-page website navigation
* Home, About, Services, Gallery, Booking, and Contact pages

Interactive Elements

* Booking enquiry form
* Contact form
* Service selection dropdown menus
* Date picker for appointment bookings
* Form validation using required fields
* Dynamic confirmation messages after form submission

Gallery

* Hairstyle image gallery
* Interactive lightbox functionality for viewing enlarged images

Contact Page

* Contact enquiry form
* Embedded Google Maps location
* Social media links

SEO Optimisation

* Title tags added to all pages
* Meta descriptions added
* Meta keywords implemented
* robots.txt file created
* sitemap.xml file created

Deployment

* Website deployed using GitHub Pages
